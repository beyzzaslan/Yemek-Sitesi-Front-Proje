# 🍽️ Food Website Frontend

A responsive food website built with **HTML5** and **CSS3**.

This project was created as part of my frontend development journey to improve my HTML and CSS skills. While building this website, I focused on writing clean code, creating responsive layouts, and gaining hands-on experience with modern CSS techniques.

---

## 🚀 Features

- Responsive design
- Modern and clean user interface
- Navigation bar
- Hero section
- Food menu section
- About section
- Contact section
- Footer
- Mobile-friendly layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

---

## 📚 What I Learned

Throughout this project, I practiced and improved my knowledge of:

- Semantic HTML
- Responsive Web Design
- CSS Flexbox
- CSS Grid
- Positioning
- Background images
- CSS transitions
- Hover effects
- Clean project structure
- Writing readable and maintainable CSS
